# Figures (v1.2)

These PNGs were produced by `src/figures/C10plus_figures_code_v1.2.py` for release v1.2, before addendum A4.

Their mass-spectrometry (MS) panels use only the two label sets from the Seer Proteograph study (MSPA and the Seer full summary statistics). The Fig. 4 heading “Under the primary MS labels, neither concordance nor anchoring tracks MS support” therefore refers to those two Seer-study layers only. In the two independent MS cohorts added in A4 (Generation Scotland and HOLBAEK; resource v2.3), platform concordance was positively associated with MS support (Generation Scotland OR 1.86, P = 0.009; HOLBAEK OR 4.67, P = 1.4 × 10⁻⁵; combined OR 2.92). Transcript (eQTL) support still did not predict MS confirmation.

The figure code (from v1.3.1) labels these headings as Seer-study results; the PNGs have not been regenerated.
